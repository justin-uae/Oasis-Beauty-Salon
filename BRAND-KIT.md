# Oasis Beauty Salon brand kit

## Original logo

The original logo supplied with the previous-site assets is retained unchanged as `public/oasis-logo.png`. The website uses `public/oasis-logo-original.svg`, which displays that exact original artwork in an SVG container for consistent sizing.

Additional files:

- `public/oasis-logo-master.png`: padded transparent master
- `public/oasis-logo-white.png`: single-colour presentation variant for dark backgrounds
- `public/oasis-logo-black.png`: single-colour presentation variant for light backgrounds
- `public/social/oasis-profile-1080.jpg`: square social profile image

## Website palette

- Ink: `#1F1A17`
- Bronze: `#866B56`
- Deep bronze: `#6A5544`
- Cream: `#F9F3ED`
- Champagne: `#E2C6AD`

- Metallic gradient (from logo): `#6A5544 → #A58972 → #F0D4BC → #C0A28A → #91755F → #CFB39D → #7B6250`

## Social photograph sizes

- Instagram square: 1080 x 1080
- Instagram portrait: 1080 x 1350
- Instagram Story or Reel cover: 1080 x 1920
- Facebook post and Open Graph: 1200 x 630
- Facebook cover: 1640 x 624
- X post: 1200 x 675
- LinkedIn post: 1200 x 627
- Google Business Profile post: 1200 x 900

Keep important faces, text, and treatment details away from the outer edges because social platforms crop images differently by device.
